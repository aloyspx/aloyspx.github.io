This is the front page of a website that is powered by the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) and hosted on GitHub pages. [GitHub pages](https://pages.github.com) is a free service in which websites are built and hosted from code and data stored in a GitHub repository, automatically updating when a new commit is made to the repository. This template was forked from the [Minimal Mistakes Jekyll Theme](https://mmistakes.github.io/minimal-mistakes/) created by Michael Rose, and then extended to support the kinds of content that academics have: publications, talks, teaching, a portfolio, blog posts, and a dynamically-generated CV. You can fork [this template](https://github.com/academicpages/academicpages.github.io) right now, modify the configuration and markdown files, add your own PDFs and other content, and have your own site for free, with no ads!

🔍 Biography
======

I'm a PhD student in Computer Engineering at Polytechnique Montréal working on machine learning for medical image analysis. My research focuses on multi-task learning and self-supervised methods, with applications in brain hemorrhage and head and neck cancer. I aim to develop models that generalize robustly across domains while simultaneously reducing the annotation burden for clinicians. Beyond research, I'm passionate about medical device innovation and entrepreneurship. In my free-time, you can find me at my local hockey rink 🏒 !
